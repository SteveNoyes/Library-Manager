# Personal Library Manager

A browser-based book collection manager built with vanilla HTML, CSS, and JavaScript. Track your reading, filter by genre, sort your collection, and search for books.

## Features

- **Add books** with title, author, year, pages, and genre
- **Filter by genre** — Fiction, Non-Fiction, Fantasy, Science, Technology, History, Biography
- **Sort** by title or publication year
- **Search** by title or author
- **Remove** books from your collection
- **Stats dashboard** showing total books, total pages, and average page count
- **Responsive design** with a warm, earthy aesthetic

## Usage

Open `index.html` in any modern web browser. No build tools, dependencies, or server required.

## Project Status

The UI and layout are fully built. Some interactive functions (add book, remove book, search, genre filtering, sorting, stats calculation) currently use stub implementations and need to be wired up to modify the library array properly.

## Tech

- HTML5
- CSS3 (Flexbox & Grid, no frameworks)
- Vanilla JavaScript (ES6)
